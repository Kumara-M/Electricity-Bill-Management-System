Electricity Bill Management System

📌 About the Project

The Electricity Bill Management System is a Java-based application developed using NetBeans. It helps calculate and manage electricity bills based on the number of units consumed by a customer.

🎯 Objectives

- To calculate electricity bills easily.
- To store customer details.
- To display electricity bill information.
- To reduce manual calculation errors.

🛠️ Technologies Used

- Programming Language: Java
- IDE: NetBeans
- Unit Rate: ₹5 per unit

⚙️ Features

- Enter customer name.
- Enter meter number.
- Enter units consumed.
- Calculate the electricity bill.
- View bill details.

🧮 Bill Calculation

Bill Amount = Units Consumed × ₹10

Example: If a customer consumes 100 units:

Bill Amount = 100 × 10 = ₹1,000

▶️ How to Run

1. Open NetBeans IDE.
2. Open the Electricity Bill Management System project.
3. Run the main Java class.
4. Enter the customer details and units consumed.
5. View the calculated bill.
